How it works

If you do not have a Keplr or Leap wallet, install one:

  • Install Keplr Wallet
  • Install Leap Wallet
🔹 Keplr (automatic)
  1. The faucet will detect your Keplr extension.
  2. It will auto-switch your network to FairyRing Testnet.
  3. Your wallet address will be filled into the input box.
🔹 Leap (manual)
  1. Open your Leap extension popup.
  2. Manually add the “Fairblock FairyRing Testnet” network.
  3. Copy your address and paste it into the faucet.

You may request FAIRY tokens once per hour.

If you already see “Tokens Sent”, please don’t submit another request. It may take some time for the testnet tokens to arrive.
