How it works

If you do not have a Keplr or Leap wallet, install one:

  • Install Keplr Wallet
  • Install Leap Wallet
🔹 After installing a wallet
  1. Click the Connect wallet button at the top-right of this page.
  2. Select Keplr or Leap.
  3. The faucet asks the wallet to add / enable Fairblock FairyRing Testnet for you.
  4. Your fairy… address is filled automatically in the input box.
  5. You’re ready – hit Request token.

Keplr users: open the extension once and click the grey “Enable” button next to Fairblock FairyRing Testnet so you can see your received tokens. (Leap does this automatically.)

You may request FAIRY tokens once per hour.

If you already see “Tokens Sent”, please don’t submit another request. Tokens can take a few minutes to arrive.
